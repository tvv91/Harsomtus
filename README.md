# Harsomtus

[English](README.md) | [Русский](README.ru.md) | [Українська](README.uk.md)

Harsomtus is a digital preservation archive for cataloging and documenting digitized physical media.

The project preserves information about music releases, source media, digitization equipment, technical parameters, provenance, and known distribution sources.

Its goal is to preserve not only the digital recordings themselves, but also the technical history and context behind their creation.
