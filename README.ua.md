# Harsomtus

[English](README.md) | [Русский](README.ru.md) | [Українська](README.uk.md)

Harsomtus — цифровий архів для каталогізації та збереження інформації про оцифровані фізичні носії.

Проєкт зберігає інформацію про музичні релізи, вихідні носії, обладнання для оцифрування, технічні параметри, походження записів та відомі джерела поширення.

Мета проєкту — зберігати не лише самі цифрові записи, а й технічну історію та контекст їх створення.
