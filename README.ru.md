# Harsomtus

[English](README.md) | [Русский](README.ru.md) | [Українська](README.uk.md)

Harsomtus — цифровой архив для каталогизации и сохранения информации об оцифрованных физических носителях.

Проект сохраняет информацию о музыкальных релизах, исходных носителях, оборудовании для оцифровки, технических параметрах, происхождении записей и известных источниках распространения.

Цель проекта — сохранять не только сами цифровые записи, но и техническую историю и контекст их создания.
